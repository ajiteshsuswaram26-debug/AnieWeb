# AnieWeb

A responsive anime/cartoon discovery website.

## Features
- Responsive desktop/mobile UI
- Search
- Language filters
- Genre filters
- Anime/movie cards
- Details modal
- Random pick
- Local favorites
- No copyrighted video files or copied streams
- Ready for static hosting (GitHub Pages, Cloudflare Pages, Netlify, Vercel, etc.)

## Publish
Upload these files to a static hosting service and replace YOUR-DOMAIN in robots.txt and sitemap.xml.
After publishing, verify the domain in Google Search Console and submit sitemap.xml.

Google does not guarantee immediate indexing.
